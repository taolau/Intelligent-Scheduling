- 09-09 滚动位置保持定稿（Tao 拍板；spec 5.1/5.2 待同步，本记录先行）：
  - **语境键驱动恢复**：语境 = 决定「看什么内容」的状态（排班 = 粒度|锚点|维度|目标；配置 = 当前 tab）。语境未变 = 纯操作刷新（保存/拖拽/替换/删除…）→ 重渲染后把视口送回原位；语境变化 = 翻页/切粒度/切维度/tab 切换/菜单重进 → 回顶（主动换内容，回顶为预期）。
  - **锚定方式**：记「视口顶第一个可见周面板序号 + 面板内偏移」/「视口顶第一张可见配置卡 data-id + 偏移」，恢复对准同锚点（data-id 优先、原索引兜底）——顶部内容增删后视口不跳位；纯像素直恢在内容高度变化时错位，只适用于静态内容（系统设置双面板）。
  - **同步渲染语义保序**：被包装的 inner 内部无 await 时须同步调用（不得 await 引入 microtask 延迟）——调用方存在「renderXxx 后立即读新 DOM」的同步路径（批量删除入口 selectable 检查），async 化会静默破坏该假设（见 pitfalls #39）。
  - **tab 切换的语境同步**：切换走轻量 activate 不经全量渲染函数时，须同步更新语境记录，否则切换后首次操作保存被误判「已换内容」而不恢复。
  - 视图层每次操作后全量重建 = 既有架构（一致性简单可靠），本次只补「滚动/视口记忆」，不推翻重建模式。
