## 🧠 核心决策
- 09-08 人员每周时间安排（availability）数据契约与交互（Tao 多轮反馈拍板；spec 3.2/4.2-13/5.1 为真源）：
  - **形态** = 顶层单选 `{mode:'unavailable'|'available', entries:[{weekDays:0-6 去重, start?, end?}]}`；**刻意不做「可用/不可用共存」**（经权衡：共存只补「白名单里抠洞」的边缘场景，可用模式拆两段 `08-10 + 12-18` 即可表达；会重载「默认开放 vs 白名单」语义、抬高录入门槛）——未来真遇痛点再升级，不必预埋。
  - **起止同时填或不填**：不填 = 整天（`00:00-24:00`）；`end > start` 不跨日；同天可多行、一行可多星期（星期列多选）。
  - **过滤双轨**（`core/filter.js` 导出 `checkAvailability`，供 filterCandidate / UI 黄字 / 自动通道复用）：任务有 timeRange → 时段级（available 合并段完整覆盖 / unavailable 半开区间相交即拒，整天并入）；任务无 timeRange → 按「当天整天/局部」判定：不可用整天命中即拒、可用整天放行、**可用当天只设局部时段 = 放行 + 黄字提醒**（不拦；分配/替换候选黄条、智能排班预览黄字区逐条单列，自动仍会排该类人）、可用当天完全没配 = 拒。
  - **UI**：字段组置于编辑弹窗末尾（四个上限字段保持原位不挪）；模式 seg **「不可用/可用」且不可用在前、为默认**（大多数人「避开式」）；默认展开一行空白行，只勾星期 = 全天，可再补起止；**切换模式只换高亮、已填行保留不清空（保存并重开才反映新模式）**；保存前过滤全空行（整组空 = 不限制）；规则说明统一收在 ⓘ help，无空态文案行、无模式副文案（Tao 嫌占地方/多余）；卡片时间行成值 = tag `已配置(可用)/已配置(不可用)`，各卡片空值统一灰字「未设置」。
  - **Excel**：新增「每周时间模式」（可用/不可用）+「每周时间段」（`周一 全天` 或 `周三 09:00-12:00`，分号多条、星期用周一~周日全称）；旧文件缺两列 = 更新保留既有配置/新增不配置；两列填了但任一段非法（缺模式/星期错/跨日/倒挂）→ **整行跳过并计数**，不静默放宽硬约束。
